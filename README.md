# Cura

AI 기반 디지털 박물관 전시 기획 시뮬레이터. 디지털헤리티지큐레이터양성과정 1차 MVP.

**사이트:** https://geonwoolim519.github.io/cura/

저장소: https://github.com/geonwoolim519/cura

당신이 큐레이터가 되어 문화유산을 고르고, 2D 전시공간에 배치하고, 관람 동선을 만든 뒤 AI 큐레이터 큐리의 평가를 받습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다.

## 전시 모드

- 국립공주박물관 (백제)
- 국립김해박물관 (가야)
- 자유주제

문화유산 이미지는 [Wikimedia Commons](https://commons.wikimedia.org/) 공개 자료를 사용합니다.
