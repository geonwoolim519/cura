Cura MVP를 구현해줘.

너는 프론트엔드 개발자, UX/UI 디자이너, 디지털 박물관 서비스 기획자 역할을 동시에 수행한다.

==================================================
1. 프로젝트 개요
==================================================

서비스명: Cura

Cura는 사용자가 직접 큐레이터가 되어
문화유산을 선택하고 전시를 구성해보는
AI 기반 디지털 박물관 전시 기획 시뮬레이터다.

Cura의 핵심은 단순히 문화유산을 감상하는 것이 아니다.

사용자가

전시관 선택
→ 전시 주제 설정
→ 문화유산 선택
→ 전시공간에 배치
→ 설명 패널 작성
→ 관람 동선 구성
→ AI 큐레이터 평가
→ 전시 수정
→ 완성된 전시 감상

의 과정을 직접 경험한다.

이번에는 실제 상용 서비스가 아니라
공모전/발표/테스트를 위한 MVP를 구현한다.

따라서 기능을 지나치게 복잡하게 만들지 말고,
핵심 사용자 경험이 실제로 작동하는 것에 집중한다.

==================================================
2. 가장 중요한 MVP 구조
==================================================

Cura의 첫 번째 핵심 화면은 다음 3가지 전시 모드를 선택하는 화면이다.

① 국립공주박물관
② 국립김해박물관
③ 자유주제

사용자가 이 세 가지 중 하나를 선택하면서
Cura의 전시 제작을 시작한다.

화면의 핵심 문구:

"어디에서 전시를 만들어볼까요?"

그리고 세 개의 큰 카드:

--------------------------------

국립공주박물관

백제의 역사와 문화유산을 바탕으로
나만의 전시를 만들어보세요.

[전시 만들기]

--------------------------------

국립김해박물관

가야의 역사와 문화유산을 바탕으로
나만의 전시를 만들어보세요.

[전시 만들기]

--------------------------------

자유주제

시대와 지역의 제한 없이
나만의 전시를 만들어보세요.

[전시 만들기]

--------------------------------

각 카드는 이미지와 간단한 설명을 가진
박물관/전시관 스타일의 카드로 만든다.

==================================================
3. 디자인 방향
==================================================

전체 디자인은

"현대적인 디지털 박물관 + 문화유산 아카이브 + 전시 기획 도구"

느낌으로 만든다.

절대로 초등학생용 교육 게임처럼 만들지 않는다.

중학생, 고등학생뿐 아니라
대학생과 일반 관람객이 사용해도 자연스러운
세련된 서비스로 디자인한다.

키워드:

- Museum
- Heritage
- Archive
- Curator
- Digital
- Minimal
- Elegant
- Calm

색상은

Ivory
White
Dark Navy
Muted Blue
Warm Gray

등을 중심으로 사용한다.

충분한 여백을 사용하고
과도한 그림자와 둥근 카드 사용을 피한다.

==================================================
4. 기술 스택
==================================================

가능하면 다음 기술을 사용한다.

React
TypeScript
Vite
Tailwind CSS
Lucide React
Framer Motion

Drag & Drop은
HTML5 Drag and Drop 또는 React DnD 등
안정적인 방법을 사용한다.

이번 MVP에서는 Three.js,
Babylon.js 등의 3D 엔진을 사용하지 않는다.

전시공간은 2D로 구현한다.

나중에 3D로 확장할 수 있도록
컴포넌트 구조는 분리한다.

==================================================
5. 문화유산 이미지 확보
==================================================

중요하다.

나는 이번 MVP에서 문화유산 이미지를 하나하나 제공하지 않는다.

따라서 가능한 경우
네가 사용할 수 있는 공개 웹 자료를 조사하여
실제 문화유산 이미지를 확보할 수 있는 구조를 만들어라.

우선순위:

1. 국립박물관 등 공공기관
2. 공공데이터
3. 공공누리 등 이용 조건이 명확한 자료
4. 기타 합법적으로 이용 가능한 공개 자료

가능하면 실제 문화유산 사진을 사용한다.

이미지의 해상도가 높지 않아도 괜찮다.

MVP에서는 기능 검증이 목적이므로
이미지 품질보다 실제 유물의 식별 가능성을 우선한다.

단,

- 출처가 불명확한 이미지
- 저작권이 명확하지 않은 이미지
- 무단으로 가져온 이미지

를 사용하지 않는다.

이미지를 직접 다운로드할 수 없는 경우에는
우선 placeholder를 사용하되,
실제 이미지 URL 또는 파일로 쉽게 교체할 수 있도록
데이터 구조를 분리한다.

각 문화유산 데이터에는 다음 정보를 포함한다.

id
name
museum
period
category
material
description
keywords
image
source
sourceUrl

예:

{
  id: 1,
  name: "...",
  museum: "국립공주박물관",
  period: "백제",
  category: "금속공예",
  material: "금",
  description: "...",
  keywords: ["백제", "금", "왕권"],
  image: "...",
  source: "...",
  sourceUrl: "..."
}

나중에 실제 이미지로 교체하기 쉽도록
이미지 경로와 문화유산 정보를 분리한다.

==================================================
6. 공주박물관 모드
==================================================

국립공주박물관 모드에서는
백제 및 충청 지역의 문화유산을 중심으로
유물 목록을 제공한다.

MVP에서는 약 10~15개의 유물을 준비한다.

대표적으로 다음과 같은 유형을 포함한다.

- 무령왕릉 관련 유물
- 금제 관식
- 금제 귀걸이
- 백제 토기
- 불교 관련 유물
- 백제 장신구
- 충청 지역의 고대 문화유산

중요:

실제 존재하는 문화유산을 사용하고
유물명과 설명을 임의로 만들어내지 않는다.

공주박물관 모드에 들어오면
화면 상단에 다음과 같이 표시한다.

"국립공주박물관"

"백제의 역사와 문화를 따라
당신만의 전시를 만들어보세요."

==================================================
7. 김해박물관 모드
==================================================

국립김해박물관 모드에서는
가야 문화유산을 중심으로
약 10~15개의 유물을 준비한다.

유물 유형 예시:

- 가야 토기
- 철제 무기
- 철제 갑옷
- 가야 장신구
- 금속공예품
- 생활용품
- 무덤 출토품
- 가야의 교역 및 생산과 관련된 유물

주제는 가야의 역사,
철 생산,
교역,
생활문화,
장례문화 등을 다양하게 구성할 수 있도록 한다.

화면 상단:

"국립김해박물관"

"가야의 역사와 문화를 따라
당신만의 전시를 만들어보세요."

==================================================
8. 자유주제 모드
==================================================

자유주제에서는
특정 박물관에 종속되지 않는다.

사용자가 직접

전시 제목
전시 주제
전시 설명

을 입력한다.

예:

전시 제목:
"금속으로 보는 한국사"

주제:
"금속은 한국인의 삶을 어떻게 변화시켰을까?"

설명:
"시대별 금속문화유산을 통해
한국의 기술과 생활문화를 살펴본다."

자유주제에서는
공주/김해 유물을 포함해
다양한 시대의 문화유산을 선택할 수 있도록
데이터 구조를 만든다.

MVP에서는 약 15~20개의
다양한 시대 문화유산을 준비한다.

==================================================
9. 전시 제작 과정
==================================================

사용자 흐름은 다음과 같아야 한다.

STEP 01
전시관 선택

STEP 02
전시 주제

STEP 03
유물 선택

STEP 04
전시공간

STEP 05
관람 동선

STEP 06
AI 큐레이터

STEP 07
전시 완성

상단에는 Progress Bar를 표시한다.

예:

01 전시관
02 주제
03 유물
04 공간
05 동선
06 AI 평가
07 완성

==================================================
10. STEP 02 — 전시 주제
==================================================

사용자가 전시 제목과 주제를 입력한다.

입력:

전시 제목
전시 주제
전시 설명

박물관 모드에서는
주제 예시도 몇 가지 보여준다.

공주:

"무령왕의 삶과 죽음"
"백제의 금속공예"
"웅진 백제의 문화"

김해:

"철의 왕국 가야"
"가야인의 생활"
"가야와 교역"

자유주제:

"금속으로 보는 한국사"
"한국인의 아름다움"
"전쟁과 문화유산"

사용자가 직접 입력할 수도 있어야 한다.

==================================================
11. STEP 03 — 유물 선택
==================================================

유물 아카이브를 만든다.

왼쪽:

검색

시대 필터
재질 필터
분류 필터

아래에 유물 카드가 나온다.

카드:

[문화유산 이미지]

유물명
시대
재질
분류

[전시에 추가]

사용자는 여러 개의 유물을 선택할 수 있다.

선택한 유물은
오른쪽 또는 상단에
"선택한 유물" 영역으로 표시한다.

==================================================
12. STEP 04 — 2D 전시공간
==================================================

Cura의 핵심 화면이다.

3개의 영역으로 구성한다.

왼쪽:
유물 라이브러리

가운데:
2D 전시공간

오른쪽:
선택한 요소의 속성

전시공간은
실제 박물관 전시실을 연상시키는
깔끔한 2D 평면 공간으로 만든다.

벽면을 표시하고
전시 영역을 구분한다.

사용자는 유물을
Drag & Drop하여
전시공간에 배치한다.

전시공간에 들어간 유물은

각 유물 데이터:

x
y
width
height
rotation
displayOrder

유물을 클릭하면
오른쪽 패널에서

유물명
시대
재질
설명

을 확인할 수 있다.

기능:

이동
크기 조절
삭제

를 구현한다.

MVP에서는 복잡한 회전 기능은
선택적으로 구현해도 된다.

==================================================
14. 설명 패널
==================================================

사용자가 전시공간에
설명 패널을 추가할 수 있게 한다.

버튼:

[+ 유물]
[+ 설명 패널]
[+ 제목]

설명 패널:

제목
내용

예:

"백제의 금속공예"

"백제에서는 금과 은을 이용한
다양한 장신구와 의례용품이 제작되었다."

설명 패널도
전시공간에서 자유롭게 이동한다.

==================================================
15. STEP 05 — 관람 동선
==================================================

사용자가 전시품의
관람 순서를 지정할 수 있도록 한다.

예:

① 무령왕릉
↓
② 금제 관식
↓
③ 금제 귀걸이
↓
④ 백제 토기

전시공간 위에는
번호와 화살표를 표시한다.

관람객이
어떤 유물부터 어떤 순서로 보는지를
사용자가 직접 결정한다.

이 기능은 Cura의 중요한 핵심 기능이다.

==================================================
16. STEP 06 — AI 큐레이터
==================================================

MVP에서는 실제 AI API를 연결하기 전에
Mock AI를 사용한다.

사용자가

[AI 큐레이터에게 평가받기]

를 클릭하면
현재 전시 데이터를 기반으로
AI 평가 화면을 보여준다.

평가 항목:

① 주제와 유물의 연결성
② 전시 구성
③ 관람 동선
④ 정보 전달력
⑤ 관람객 경험

각 항목을 100점 만점으로 표시한다.

예:

주제와 유물의 연결성
86

전시 구성
82

관람 동선
74

정보 전달력
84

관람객 경험
88

종합 점수
83

그리고 평가 이유를 보여준다.

예:

"선택한 유물들이 '백제의 금속문화'라는
주제와 전반적으로 잘 연결되어 있습니다.

다만 현재 관람 동선에서는
유물 간 시대적 흐름이 명확하지 않습니다.

제작 기술 → 대표 유물 → 실제 사용 방식
순으로 배치하면 관람객이 전시의 흐름을
더 쉽게 이해할 수 있습니다."

중요:

AI는 사용자의 전시를 대신 결정하지 않는다.

AI는 "정답"을 제시하는 것이 아니라
큐레이터의 관점에서 조언한다.

따라서

"잘못된 전시입니다."

같은 표현보다는

"현재 구성에서는 관람객이
두 유물의 관계를 이해하기 어려울 수 있습니다."

같은 방식으로 표현한다.

==================================================
17. 관람객 관점
==================================================

AI 평가 화면에
관람객 관점 선택 기능을 추가한다.

선택:

일반 관람객
청소년
외국인 관람객
역사 전공자

예:

[청소년]

"유물 설명이 다소 길어
처음 보는 관람객에게는 어려울 수 있습니다."

[외국인 관람객]

"백제에 대한 기본적인 설명을
전시 초반에 추가하면 이해하기 쉬울 수 있습니다."

이 기능을 통해
사용자가 단순히 전시를 만드는 것이 아니라
"관람객이 어떻게 전시를 경험할 것인가"까지
생각하도록 만든다.

==================================================
18. STEP 07 — 전시 미리보기
==================================================

AI 평가 후
[전시 보기] 버튼을 제공한다.

편집 UI를 모두 숨기고
실제 전시를 관람하는 것처럼 보여준다.

화면:

전시 제목

전시공간

유물

설명 패널

관람 동선

하단:

[← 이전]
[다음 →]

유물을 클릭하면
상세 설명이 나온다.

마지막:

"전시 관람 완료"

==================================================
20. localStorage
==================================================

로그인 시스템은 만들지 않는다.

현재 전시 데이터는
localStorage에 저장한다.

새로고침해도
현재 작업이 유지되어야 한다.

저장할 데이터:

museumMode
title
theme
description
selectedArtifacts
placedArtifacts
panels
route
aiEvaluation

22. 데이터 구조
==================================================

박물관별 데이터를 분리한다.

예:

data/
  artifacts/
    gongjuArtifacts.ts
    gimhaeArtifacts.ts
    freeArtifacts.ts

또는 JSON 형태를 사용한다.

중요한 것은
박물관별 유물 데이터를 쉽게 추가/삭제할 수 있는 구조다.

공주박물관 모드를 선택하면
공주박물관 관련 유물만 기본적으로 표시한다.

김해박물관 모드를 선택하면
김해박물관 관련 유물만 기본적으로 표시한다.

자유주제에서는
전체 유물 아카이브를 사용할 수 있도록 한다.

==================================================
23. 박물관 공간 디자인
==================================================

공주박물관과 김해박물관은
각각 다른 전시공간을 보여준다.

단, 실제 박물관 건물을
정밀하게 3D 복제할 필요는 없다.

MVP에서는 2D 전시실 레이아웃으로 표현한다.

예:

공주박물관

┌──────────────────────────┐
│        전시실 A           │
│                          │
│  [벽면]       [벽면]      │
│                          │
│     ①          ②         │
│                          │
│            ③             │
│                          │
│  입구 →                  │
└──────────────────────────┘

김해박물관

┌──────────────────────────┐
│        전시실 A           │
│                          │
│  ①      ②       ③       │
│                          │
│                          │
│      ④        ⑤          │
│                          │
│                    출구   │
└──────────────────────────┘

각 박물관의 공간 구성은
MVP에 적합하도록 단순화한다.

실제 건축 구조를 정확히 재현했다고
표현하지 않는다.

==================================================
24. 2D 우선 원칙
==================================================

이번 MVP에서는
3D를 구현하지 않는다.

Cura의 핵심은

"3D 박물관을 보는 것"

이 아니라

"내가 직접 전시를 기획하는 것"

이다.

따라서 개발 리소스는

Drag & Drop
유물 선택
전시 배치
설명 패널
동선
AI 피드백

에 우선적으로 사용한다.

향후에는

ExhibitionCanvas2D
↓
ExhibitionCanvas3D

로 확장할 수 있도록
구조를 분리한다.

25. UI에서 강조할 핵심 문구
==================================================

Cura

"당신이 큐레이터가 되어
하나의 전시를 만들어보세요."

전시관 선택:

"어디에서 전시를 만들어볼까요?"

공주박물관:

"백제의 이야기를
당신만의 전시로 만들어보세요."

김해박물관:

"가야의 이야기를
당신만의 전시로 만들어보세요."

자유주제:

"당신이 상상하는 전시를 만들어보세요."

AI:

"AI 큐레이터의 시선으로
당신의 전시를 돌아보세요."

완성:

"당신만의 전시가 완성되었습니다."

27. 최종 MVP 기준
==================================================

완성된 사이트를 처음 보는 사람이
5초 안에

"아, 이건 문화유산을 직접 골라서
내가 박물관 전시를 만들어보는 서비스구나."

라고 이해할 수 있어야 한다.

특히 발표 시 다음 흐름을
끊김 없이 시연할 수 있어야 한다.

Cura 접속
↓
공주박물관 선택
↓
"백제의 금속문화" 입력
↓
유물 선택
↓
유물을 전시공간으로 Drag & Drop
↓
유물 위치 조정
↓
설명 패널 추가
↓
관람 동선 설정
↓
AI 큐레이터 평가
↓
청소년 관람객 관점 확인
↓
전시 Preview
↓
완성

이 전체 흐름이 이번 MVP의 핵심이다.

==================================================
28. 개발 완료 후
==================================================

개발이 끝나면 다음을 확인한다.

- npm run dev가 정상적으로 실행되는가?
- 모든 페이지 이동이 작동하는가?
- 공주박물관 모드가 작동하는가?
- 김해박물관 모드가 작동하는가?
- 자유주제 모드가 작동하는가?
- 유물 선택이 작동하는가?
- Drag & Drop이 작동하는가?
- 유물 삭제가 작동하는가?
- 설명 패널 추가/삭제가 작동하는가?
- 관람 동선이 작동하는가?
- Preview가 작동하는가?
- AI 평가 화면이 작동하는가?
- localStorage가 작동하는가?
- 새로고침 후 데이터가 유지되는가?
- 화면이 깨지는 부분이 없는가?

문제가 있으면 먼저 수정한 뒤
완성된 MVP 상태로 만들어라.

가장 중요한 것은
기능의 숫자가 아니라
"사용자가 큐레이터가 되어 전시를 만드는 경험"이
자연스럽게 느껴지는 것이다.
