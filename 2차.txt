현재 구현되어 있는 CURA 웹앱을 처음부터 다시 만들지 말고,
기존의 기능과 컴포넌트 구조를 최대한 유지하면서
전체적인 UI/UX 완성도와 콘텐츠 밀도를 크게 높여줘.

이번 작업의 핵심은 단순히 기능을 추가하는 것이 아니라,
현재 웹사이트가 가지고 있는 "프로토타입 / 개발자 데모" 느낌을 줄이고

"실제로 출시를 준비하고 있는 디지털 박물관 서비스"

처럼 보이게 만드는 것이다.

특히 현재 화면에서 가장 큰 문제는 다음과 같다.

1. 화면에 빈 공간이 많아 전체적으로 휑해 보인다.
2. 카드와 버튼의 디자인이 반복적이고 단순하다.
3. 박물관 전시실 에디터가 단순한 사각형 캔버스처럼 보여 실제 전시를 기획하는 느낌이 부족하다.
4. 박물관별 개성이 없다.
5. 유물 선택 화면의 정보 밀도가 낮다.
6. AI 평가 화면이 일반적인 점수 화면처럼 보인다.
7. 전체적으로 좋은 색상과 로고는 있지만 서비스만의 "박물관 + 디지털 + 큐레이션" 감성이 충분히 살아나지 않는다.
8. 현재의 캐릭터와 CURA 로고는 이미 확정되었으므로 절대 새로 디자인하지 않는다.

--------------------------------
[0. 절대 변경하지 말아야 할 브랜드 요소]
--------------------------------

현재 적용된 다음 요소는 유지한다.

- CURA 로고
- CURA 앱 아이콘
- Curi 캐릭터
- 기존 네이비 / 아이보리 / 블루 계열 브랜드 컬러
- "CURATE YOUR EXHIBITION" 문구
- 전체적인 차분하고 세련된 박물관 분위기
- 한글 중심의 UI
- 현재 사용 중인 세리프 계열 제목 폰트의 분위기

Curi 캐릭터를 지나치게 많이 배치하지 않는다.

캐릭터는 서비스의 마스코트이지 모든 화면을 장식하는 요소가 아니다.

주요 위치:
- 홈 Hero
- AI 평가 화면
- 완성 화면
- 필요한 경우 empty state

정도만 사용한다.

--------------------------------
[1. 전체 디자인 방향]
--------------------------------

현재의 "네이비 + 크림" 색상 조합은 유지하되
다음 키워드를 기준으로 UI를 전면적으로 정리한다.

KEYWORDS:

- Museum Editorial
- Digital Heritage
- Modern Curatorial
- Premium
- Calm
- Academic
- Interactive
- Cultural
- Minimal but rich

절대로 다음과 같은 느낌이 나지 않게 한다.

- 어린이용 교육 앱
- 게임 UI
- 과도하게 둥근 SaaS UI
- 쇼핑몰
- 일반적인 AI 서비스
- 과도한 그라데이션
- 지나치게 많은 그림자
- 과도한 카드 중첩

카드의 border-radius는 현재보다 약간 줄여
전문적인 박물관/전시 디자인 느낌을 준다.

전체적으로
"국립박물관의 전시 안내물 + 현대적인 디지털 서비스"
사이의 분위기를 목표로 한다.

--------------------------------
[2. 화면의 빈 공간을 줄이고 시각적 밀도를 높여라]
--------------------------------

현재 페이지는 콘텐츠가 중앙에 작게 모여 있어
1920px 데스크톱 화면에서 양쪽에 지나치게 많은 빈 공간이 발생한다.

이를 개선한다.

권장:

- max-width: 1440~1520px
- 콘텐츠 영역을 적극적으로 사용
- Hero 영역은 이미지와 텍스트가 충분히 크게 보이도록 구성
- 카드 이미지 비율 확대
- 섹션 사이의 간격은 유지하되 지나치게 넓게 만들지 않는다.
- 단순한 빈 배경 대신 작은 정보 요소, 메타데이터, 카테고리, 태그 등을 적절히 사용한다.

특히 1920px 화면에서도
"콘텐츠가 가운데 작은 박스 하나 있는 느낌"이 아니라
하나의 완성된 웹서비스 화면처럼 보여야 한다.

작은 번호 + 선(line) + 아이콘을 이용한 editorial timeline 형태로 만든다.

[8. 가장 중요: 전시실 에디터를 크게 개선]
--------------------------------

현재 가장 개선이 필요한 부분이다.

현재의 단순한 크림색 사각형 공간은
실제 전시실처럼 보이지 않는다.

"전시실을 디자인한다"는 느낌이 확실히 들어야 한다.

전시실은 2D 기반을 유지한다.

Three.js 같은 3D 기술은 이번 단계에서 사용하지 않는다.

하지만 2D 그래픽만으로
실제 박물관 전시실처럼 보이도록 만든다.

전시실에는 다음 요소를 넣는다.

- 바닥
- 벽
- 벽면 전시 영역
- 중앙 전시대
- 유물 받침대
- 쇼케이스
- 설명 패널
- 작품/유물 라벨
- 입구
- 출구
- 관람객 동선
- 조명 효과
- 공간 구분

전시실 배경을 단순한 빈 사각형으로 만들지 않는다.

[12. 동선 설계 기능 개선]
--------------------------------

현재 동선 기능도 단순한 숫자와 화살표만 보여주지 말고
실제 큐레이터가 관람객의 이동을 설계하는 느낌을 준다.

관람 동선:

① 입구
↓
② 첫 번째 유물
↓
③ 두 번째 유물
↓
④ 핵심 유물
↓
⑤ 마지막 유물
↓
출구

사용자가 유물을 클릭하면

"동선 01"
"동선 02"

등으로 지정할 수 있게 한다.

화살표는 전시실 바닥 위에 표시한다.

동선이 겹치거나
너무 짧거나
중앙 전시물을 지나치거나
전시 공간을 제대로 사용하지 않으면
AI 평가에서 관련 피드백을 제공한다.

다만 현재 핵심 유물이 중앙에 집중되어 있어
관람객의 시선이 한 곳에 머무를 가능성이 있습니다.

두 번째 유물을 입구 쪽으로 이동하면
전시의 흐름을 보다 자연스럽게 만들 수 있습니다."

즉,

AI가 단순히 점수를 주는 것이 아니라
"왜 그렇게 평가했는지"를 설명한다.

[17. 박물관별 최소 유물 데이터]
--------------------------------

MVP에서는 각 박물관마다 최소 10~15개의 유물을 제공한다.

따라서 총 50~75개의 유물 데이터 구조를 만든다.

단, 실제 이미지를 무리하게 새로 생성하지 않는다.

실제 문화유산 이미지를 사용하는 경우
반드시 다음 정보를 데이터에 포함한다.

- image
- source
- sourceUrl
- rights/license

이미지 권리가 불명확한 자료는 사용하지 않는다.

현재 사용 중인 Wikimedia Commons 기반 이미지는
가능한 경우 유지한다.

The Met의 경우에도
권리 상태가 확인된 공개 이미지 위주로 사용한다.

이미지 출처는 UI의 유물 상세 화면에 작게 표시한다.

[29. 중요한 디자인 원칙]
--------------------------------

현재 화면의 가장 큰 문제는
"기능은 많은데 화면이 기능 목록처럼 보인다"는 것이다.

따라서 각 화면을

기능 → 카드 → 버튼

방식으로만 만들지 않는다.

각 페이지마다

1. Editorial Header
2. Main Visual
3. Primary Content
4. Supporting Information
5. Action

이라는 계층을 만든다.

화면에 정보가 부족하면
불필요한 장식물을 넣는 것이 아니라
"큐레이션에 도움이 되는 정보"를 추가한다.

동선:
"관람객의 경험을 직접 설계하는 것 같다."

"AI가 큐레이터처럼 내 전시를 분석해주는 것 같다."

"내가 하나의 전시를 완성했다는 성취감이 있다."

--------------------------------
[32. 매우 중요]
--------------------------------

현재 작동하는 기능을 함부로 제거하지 않는다.

기존 routing, state management, localStorage, drag & drop 기능 등이 있다면
그 구조를 최대한 유지하면서 개선한다.

새로운 라이브러리를 추가하기 전에
현재 프로젝트에 설치된 라이브러리를 우선 사용한다.

불필요하게 Three.js를 추가하지 않는다.

3D 구현은 이번 버전에서 하지 않는다.

현재의 Curi 캐릭터와 CURA 로고를 새롭게 생성하거나 변경하지 않는다.

현재 브랜드 컬러를 완전히 바꾸지 않는다.

CURA의 핵심은 "예쁜 박물관 웹사이트"가 아니라
"사용자가 직접 전시를 기획하는 디지털 큐레이션 서비스"라는 점을 유지한다.

마지막으로 전체 페이지를 실제 서비스처럼 연결하고,
각 단계에서 다음 단계로 자연스럽게 이동할 수 있도록 한다.

최종적으로
"국립공주박물관 → 국립김해박물관 → 국립경주박물관 → 국립제주박물관 → The Met"
5개 박물관을 각각 선택하여
주제 → 전시품 → 공간 → 동선 → AI 평가 → 완성까지
독립적으로 체험할 수 있도록 구현한다.
